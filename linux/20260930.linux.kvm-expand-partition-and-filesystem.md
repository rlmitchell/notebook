
## On Host

expand the qcow2 disk file
```
qemu-img resize disk.qcow2 +20G
```


## On VM

```
rob@snowball:~$ grep 'VERSION=' /etc/os-release
VERSION="22.04.5 LTS (Jammy Jellyfish)"
rob@snowball:~$ 
```

Required
```
sudo apt update
sudo apt install cloud-guest-utils
```

Expand the partition (/dev/vda3)
```
sudo growpart /dev/vda 3
```

Expand the filesystem. Do this mounted. 
```
sudo resize2fs /dev/vda3
```
